0. Beginner introduction

Physical intuition: why thin films? Have you ever noticed iridescent colors on a soap bubble or an oil slick? That is thin-film optics in action. Part of the light reflects at the first interface (air/oil), and another part enters, travels, and reflects at the second (oil/water).

When these rays recombine, they interfere. Depending on layer thickness, some colors cancel (destructive interference) and others reinforce (constructive interference). Thin-film engineering stacks materials with nanometre precision to control exactly which colors are transmitted or reflected.

Instead of summing by hand the infinite series of internal bounces in each layer, physicists use a global approach: the matrix method. Each layer is represented by a 2×2 matrix; the effect of 50 layers is just the product of 50 matrices.

1. Core conventions and glossary

Geometry note: the stack is numbered from $j=1$ (layer next to the substrate) to $j=N$ (layer next to air).

Critical for code: complex index The refractive index is complex: $\hat{n} = n - i\kappa$.
The minus sign on $i\kappa$ follows Macleod’s convention. Using $\hat{n} = n + i\kappa$ with the matrices in this document would yield unphysical results where materials create energy.

2. Transfer-matrix method (TMM)

What is this matrix for? The electromagnetic field has electric $E$ and magnetic $H$ parts. The characteristic matrix $M_j$ of a layer relates $(E, H)$ at the input and output faces of that layer exactly.

2.1 Matrix of layer $j$

For a layer with index $\hat{n}_j$ and thickness $d_j$, the matrix $M_j$ is:

$$ M_j = \begin{pmatrix} \cos \delta_j & \frac{i}{\eta_j} \sin \delta_j \\ i \eta_j \sin \delta_j & \cos \delta_j \end{pmatrix} $$

Here $\delta_j$ is the phase accumulated across the layer: $\delta_j = \frac{2\pi}{\lambda} (n_j - i\kappa_j) d_j \cos \theta_j$.

The “branch cut” pitfall (complex square root)

Context: Snell’s law gives $S_0 = n_0 \sin \theta_0$. To get $\cos \theta_j$, one uses $\cos \theta_j = \frac{\sqrt{\hat{n}_j^2 - S_0^2}}{\hat{n}_j}$. The trap is how $\sqrt{z}$ is computed in software.

$f(z) = \sqrt{z}$ is multivalued on $\mathbb{C}$. In Python/NumPy, np.sqrt(z) returns the root with real part $\ge 0$. That fails when $z = \hat{n}_j^2 - S_0^2$ lies in the left half-plane ($\text{Re}(z) < 0$), which is typical for highly absorbing metals ($\kappa \gg n$) at oblique incidence.

Physical derivation of the constraint

The electric field in layer $j$ is $E_j(z,t) = E_0 \exp[i(\omega t - k_{z,j} z)]$ with $k_{z,j} = \frac{2\pi}{\lambda} \hat{n}_j \cos\theta_j$. For the amplitude to decay as $z$ increases (attenuation in matter), one must enforce:

$$ \text{Im}(\hat{n}_j \cos\theta_j) \leq 0 \quad \text{(Convention } n-i\kappa \text{)}$$

Numerical example (silver @ 550 nm, 45°)

Data: $\hat{n}_{Ag} = 0.12 - 3.45i$, $\theta_0 = 45°$. Then $z = \hat{n}_{Ag}^2 - S_0^2 = -12.388 - 0.828i$. NumPy gives $w = \sqrt{z} = 0.118 + 3.519i$. Here $\text{Im}(w) > 0$ is the wrong sign (unphysical gain). Fix with $w_{corr} = -w$.

Vectorized fix (Python)

def safe_cos_theta_vectorized(n_layers, S0):
    n_cos = np.sqrt(n_layers**2 - S0**2 + 0j)
    mask = n_cos.imag > 0
    n_cos[mask] *= -1
    return n_cos / n_layers

Ref: S.J. Byrnes, “Multilayer optical calculations”, arXiv:1603.02720 (2016), § 5.2

2.2 Global stack matrix

The stack matrix $M$ is the product of layer matrices. In CERTUS, layers are indexed from the substrate up to the air. We multiply from the substrate side (layer 1) toward the incident medium (layer $N$):

$$ M = \begin{pmatrix} m_{11} & m_{12} \\ m_{21} & m_{22} \end{pmatrix} = M_N \cdot M_{N-1} \cdots M_1 $$

3. Polarization and optical admittance

At oblique incidence, $\eta_j$ depends on field orientation:

PolarizationTypeAdmittance $\eta_j$

TM (p)Magnetic field parallel to the surface$$ \eta_j^{(p)} = \frac{\hat{n}_j}{\cos \theta_j} $$

4. Reflectance (R) and transmittance (T)

TL;DR: R and T Once the full matrix $M$ is known, apply it at the exit substrate to get reflected amplitude $r$ and transmitted amplitude $t$. Powers follow: measurable energy is $R$ and $T$.

Define the characteristic vector:

$$ \begin{pmatrix} B \\ C \end{pmatrix} = M \cdot \begin{pmatrix} 1 \\ \eta_{sub} \end{pmatrix} $$

Amplitude (Fresnel) coefficients: $r = \frac{\eta_0 B - C}{\eta_0 B + C} \quad \text{and} \quad t = \frac{2 \eta_0}{\eta_0 B + C}$

Power ($R+T+A=1$):

Reflectance $R$: $$ R = |r|^2 $$ Transmittance $T$: $$ T = \frac{\Re(\eta_{sub})}{\Re(\eta_{0})} |t|^2 $$
Why $T \neq |t|^2$? Poynting flux and oblique incidence

A common mistake is to set $T = |t|^2$. Transmittance is a ratio of energy flux through the surface (Poynting vector $\vec{S}$), not a simple ratio of electric-field amplitudes.

Poynting vector and geometric projection ($\cos \theta$)

Total intensity carried by a wave (magnitude of $\vec{S}$) scales with medium index: $|\vec{S}| = \frac{1}{2} \text{Re}(\hat{n}) |E|^2$. For energy that actually crosses an interface (e.g. air/glass), only the normal component of flux matters: $S_z$.

At oblique incidence (angle $\theta$), a beam of spatial width $W$ illuminates a footprint $W/\cos\theta$ on the interface. Power per unit area crossing the interface is therefore reduced geometrically by $\cos\theta$.

Mathematically, projecting this flux gives:

$$ S_z = |\vec{S}| \cos\theta = \frac{1}{2} \text{Re}(\hat{n}) \cos\theta \, |E|^2 = \frac{1}{2} \text{Re}(\underbrace{\hat{n} \cos\theta}_{\text{Admittance } \eta}) \, |E|^2 $$

Note the key term $\hat{n} \cos\theta$: it is exactly the optical admittance for TE (s) polarization. (For TM, tangential-field definitions lead similarly to $\eta_p = \hat{n} / \cos\theta$.) Admittance $\eta$ is not just a matrix trick: it physically combines material index and beam projection.

The universal normal-flux formula is then:

$$ \langle S_z \rangle = \frac{1}{2} \text{Re}(\eta) \, |E|^2 $$

Energy balance at the interface

Reflectance stays simple because incident and reflected waves share the same medium ($R = |r|^2$). The transmitted wave enters a new medium, hence the ratio of real parts of admittances: $T = \frac{\text{Re}(\eta_{\text{exit}})}{\text{Re}(\eta_0)} |t|^2$.

Typical correction factors

CaseFactor $\frac{\text{Re}(\eta_{\text{exit}})}{\text{Re}(\eta_0)}$
Incidence normale ($\kappa=0$)$n_{\text{exit}} / n_0$
Oblique pol. s ($\kappa=0$)$(n_{\text{exit}} \cos\theta_{\text{exit}}) / (n_0 \cos\theta_0)$
Oblique pol. p ($\kappa=0$)$(n_{\text{exit}} / \cos\theta_{\text{exit}}) / (n_0 / \cos\theta_0)$

Note: if the substrate absorbs ($\kappa_{sub} > 0$), the computed power T is not flux to infinity; it is power entering the substrate and absorbed over its thickness.

5. Front surface, back surface, and finite substrate

The formulas above assume a semi-infinite substrate. Real glass has finite thickness. Inside thick glass, coherence is lost (no interference), so one sums intensities (not amplitudes) of successive bounces between the stack (front) and the bottom of the plate (back).

Full formula (thickness $D$ and absorption $\alpha = \frac{4\pi \kappa_{sub}}{\lambda}$): $$ R_{total} = R_{front} + \frac{T_{front}^2 \cdot R_{back} \cdot e^{-2 \alpha D}}{1 - R'_{front} \cdot R_{back} \cdot e^{-2 \alpha D}} $$ $$ T_{total} = \frac{T_{front} \cdot T_{back} \cdot e^{-\alpha D}}{1 - R'_{front} \cdot R_{back} \cdot e^{-2 \alpha D}} $$

Simplified (transparent glass, $\alpha=0$): $R_{total} \approx R_{front} + \frac{T_{front}^2 R_{back}}{1 - R'_{front} R_{back}}$

Bare glass reflects about 4% from the back; a simple pane therefore has $R_{total} \approx 4\% + 4\% = 8\%$.

“Front” (air→sub) and “back” (sub→air) calculations

For the incoherent-reflection formula, you need optical properties as seen from inside the substrate ($R'_{front}$). The matrix multiplication order reverses.

  • FRONT (standard): $M_{tot} = M_N \cdot M_{N-1} \cdots M_1$. Matrix applied with exit medium $n_{sub}$.
  • BACK (from inside): $M_{back} = M_1 \cdot M_2 \cdots M_N$. Light starts in the substrate; air is the exit medium. Used to obtain $R'_{front}$.
Absorption and electric-field profile $|E(z)|^2$

Energy balance: $R + T + A = 1$. Absorption $A$ occurs in material layers (e.g. metals).

To get the intensity profile $|E(z)|^2$ inside the stack, propagate backward from the exit substrate (only the transmitted wave, $E^+_{inc} = t$) using partial layer matrices:

$$ \begin{pmatrix} E(d') \\ H(d') \end{pmatrix} = \begin{pmatrix} \cos \delta(d') & \frac{i}{\eta_j} \sin \delta(d') \\ i \eta_j \sin \delta(d') & \cos \delta(d') \end{pmatrix} \begin{pmatrix} E_{next} \\ H_{next} \end{pmatrix} $$

with $\delta(d') = \frac{2\pi}{\lambda} (n_j - i\kappa_j) d' \cos \theta_j$. Plotting $|E(d')|^2$ shows where light is absorbed or enhanced in the design.

6. Simple example: quarter-wave antireflection layer

Goal: cancel reflection (R=0) To wipe out glass’s ~4% natural reflectance, add a thin layer that makes the wave reflected at the top surface interfere destructively with the wave from the bottom of that layer.

The layer must add a round-trip phase of half a wave. Its one-way optical thickness is therefore quarter-wave (QWOT): $n \cdot d = \frac{\lambda_0}{4}$, so $\delta = \pi/2$.

Simplified matrix: $$ M_{QWOT} = \begin{pmatrix} 0 & \frac{i}{n} \\ i n & 0 \end{pmatrix} $$

Reflectance vanishes if $n_{layer} = \sqrt{n_{air} \cdot n_{glass}}$. For glass one would need $n \approx 1.23$. Magnesium fluoride (MgF₂, $n=1.38$) is close—that is the typical purple tint on eyeglasses.

8. Complete generalized Python code

This robust snippet covers absorption, oblique incidence, polarization, field profile, and incoherent back reflections.

import numpy as np

def compute_tmm_general(n_inc, n_exit, n_layers, d_layers, wavelength, theta0=0.0, pol='s', compute_field=False):
    """
    Generalized TMM (Macleod n−ik).
    Returns: dict with 'R', 'T', 'A', and optional 'E_profile'.
    """
    # 0. Macleod convention (n − ik) — safety check
    def enforce_macleod(n): return n if n.imag <= 0 else n.real - 1j*n.imag
    
    n_inc = enforce_macleod(n_inc)
    n_exit = enforce_macleod(n_exit)
    n_layers = [enforce_macleod(n) for n in n_layers]
    k0 = 2 * np.pi / wavelength
    
    # 1. Snell's law and branch-cut fix (Byrnes)
    S0 = n_inc * np.sin(theta0) 
    
    def safe_cos_th(n):
        n_cos_th = np.sqrt(n**2 - S0**2 + 0j)
        if n_cos_th.imag > 0: n_cos_th = -n_cos_th 
        return n_cos_th / n

    cos_inc = np.cos(theta0) 
    cos_exit = safe_cos_th(n_exit)
    cos_layers = [safe_cos_th(n) for n in n_layers]
    
    # 2. Modified admittances (eta)
    def get_eta(n, cos_th, pol):
        return n * cos_th if pol.lower() == 's' else n / cos_th
            
    eta_inc = get_eta(n_inc, cos_inc, pol)
    eta_exit = get_eta(n_exit, cos_exit, pol)
    eta_layers = [get_eta(n_layers[i], cos_layers[i], pol) for i in range(len(n_layers))]
    
    # 3. Matrix multiplication
    M_sys = np.eye(2, dtype=complex)
    if compute_field: matrices = []
        
    for i in range(len(n_layers)):
        delta = k0 * n_layers[i] * d_layers[i] * cos_layers[i]
        c, s = np.cos(delta), 1j * np.sin(delta)
        eta = eta_layers[i]
        
        M_i = np.array([[c, s/eta], [s*eta, c]], dtype=complex)
        if compute_field: matrices.append(M_i)
        M_sys = np.dot(M_i, M_sys)

    # 4. Final coefficients
    B = M_sys[0,0] + M_sys[0,1] * eta_exit
    C = M_sys[1,0] + M_sys[1,1] * eta_exit
    
    r = (eta_inc * B - C) / (eta_inc * B + C)
    t = (2.0 * eta_inc) / (eta_inc * B + C)
    
    R = abs(r)**2
    T_factor = (eta_exit.real) / (eta_inc.real) if eta_inc.real > 1e-12 else 0.0
    T = T_factor * abs(t)**2
    
    res = {'R': R, 'T': T, 'A': 1 - R - T}

    # 5. E-field profile E(z)
    if compute_field:
        vec_curr = np.array([t, eta_exit * t])
        z_coords, E_sq = [0.0], [abs(vec_curr[0])**2]
        z_accum = 0.0
        
        for i in range(len(n_layers)):
            res['E_profile'] = (z_coords, E_sq)
        
    return res

def apply_incoherent_backside(R_front, T_front, R_back, T_back, thickness_sub=0.0, alpha_sub=0.0, R_front_prime=None):
    """Total R, T including incoherent back surface and substrate absorption."""
    if R_front_prime is None:
        R_front_prime = R_front # Approximation (exact if layers are lossless)
        
    A = np.exp(-alpha_sub * thickness_sub)
    denom = 1.0 - R_front_prime * R_back * A**2
    if abs(denom) < 1e-10: denom = 1.0
        
    R_tot = R_front + (T_front**2 * R_back * A**2) / denom 
    T_tot = (T_front * T_back * A) / denom
    return R_tot, T_tot
