CERTUS-RE

Reverse Engineering from Measured Spectra

Scientific Revision Pro 2026 — RE Worker & Batch Tooling

Executive Summary: CERTUS-RE solves a constrained nonlinear least-squares inverse problem: find physical layer thicknesses and smooth corrections \(\Delta\mathrm{Re}\) to high/low index dispersions (and optionally a Cauchy substrate tail) such that simulated R/T from the shared oblique transfer-matrix stack matches tabulated measurements. The optimiser is TRF (trust-region reflective) on a vector residual built from \(1/\sqrt{\lambda}\)-weighted spectral error plus a QWOT channel at a reference wavelength, with dead zones, Tikhonov curvature on spline knots, and an HL \(\sqrt{w}\) penalty on \(\Delta\mathrm{Re}\) relative to a wavelength-dependent envelope. RMSE* is a post-hoc ranking scalar with fixed \(\alpha_\mathrm{ref}\), independent of phase-varying \(\alpha\) used inside the fit. This document ties each mechanism to what you configure in the GUI or Excel and what appears in logs.

1. Scope and Positioning

CERTUS-DESIGN optimises a target spectrum under fabrication and material constraints. CERTUS-RE solves the inverse problem: given one or more measured curves (and workbook metadata), recover thicknesses and per-material dispersion corrections that explain the data while staying physically plausible.

Design principle: Forward model, gradient sources, and wavelength sampling must match the evaluation path used elsewhere in CERTUS. RE is not a separate “black box” optimiser; it reuses the stack representation, oblique TMM, and material tables from the shared physics layer.

3. Forward Model — What Is Actually Simulated

For each optimisation step, CERTUS-RE evaluates the same oblique, polarised TMM path as the evaluation worker: layer refractive indices (including your \(\Delta\mathrm{Re}\) splines and optional substrate Cauchy correction) and thicknesses feed into calc_spectrum_oblique_vectorized (and related kernels) from the shared certus_physics stack. Targets are grouped by (angle, polarisation, backside flag); within a group, one spectrum computation is reused for all targets sharing that geometry, which is why logs report “spectral blocks” and active target counts.

User takeaway: If measured R and T at \(45^\circ\) s- and p-pol are loaded, the code may report two physics groups. Each group’s residual is accumulated into the global least-squares vector; weights and wavelength masks are applied per target band as defined in the workbook.

4. Excel Workbook — Concrete Data Flow

The RE spreadsheet encodes: (1) stack order and nominal thicknesses (starting point \(d^{(0)}\)); (2) material IDs mapping to tabulated \(n(\lambda)\); (3) one or more target strips — each with type R or T, incidence, polarisation, wavelength interval \([\lambda_\mathrm{min},\lambda_\mathrm{max}]\), a scalar band weight tgt.w, and the measured value channel. The GUI loads this into in-memory structures; headless mode uses the same parser. The optimisation grid uses RE_OPTIM_POINTS_PER_TARGET = 1: effectively one objective sample per active target row per wavelength index after masking (see source for exact alignment with measurement columns).

4.1 What you should verify before clicking “Run”

  • Angles / pol match the spectrometer configuration; mixed groups are handled but cost more forward models.
  • \(\lambda\) range overlaps the spline knot design (IR knots exist up to 4800 nm in the default basis); extrapolation relies on spline + envelope design — avoid empty bands.
  • Reference wavelength \(\lambda_0\) (QWOT anchor) is consistent with your physical interpretation of “quarter-wave” drift (logged as lambda_ref).

5. Objective Function — Spectral + QWOT (How RMSE∑ Is Built)

5.1 Spectral channel (1/√λ weighting)

For each target, contributions inside its wavelength mask use a per-point weight \(w_\lambda(\lambda_i)=1/\sqrt{\max(\lambda_i,1\,\mathrm{nm})}\), the same as in _re_rmse_oblique_weighted. This down-weights noisy short-λ channels relative to a uniform RMS and matches the TRF residual assembly. The GUI spin for target importance maps to an extra per-target scalar multiplier on top of \(w_\lambda\).

\[ \text{RMSE}_\mathrm{spec} \;\text{is the root-mean weighted error over all (target, }\lambda_i\text{) pairs in the mask, with weights } w_\lambda \times w_\mathrm{tgt}. \]

5.2 QWOT channel (optical thickness drift at \(\lambda_0\))

At reference wavelength \(\lambda_0\), each layer contributes an optical thickness proportional to \(n\,d\). The code forms a quarter-wave normalised excess versus the initial stack \(d^{(0)}\) (and nominal \(n\) at \(\lambda_0\), with spline corrections applied when active). A dead zone \(\varepsilon_Q\) (default 0.01 in QWOT units) zeros small residuals: contributions use \(\max(|\Delta Q|-\varepsilon_Q, 0)\) when reporting penalised QWOT RMSE; the ranking metric RMSE* uses the raw RMS without dead zone for comparability across batches.

5.3 Combined objective during optimisation (RMSE∑)

During TRF, the scalar reported as RMSE∑ (or “RMSE_combined”) is

\[ \mathrm{RMSE}_\Sigma = \sqrt{\mathrm{RMSE}_\mathrm{spec}^2 + \alpha_\mathrm{phase}\,\mathrm{RMSE}_\mathrm{QWOT}^2} \]

with \(\alpha_\mathrm{phase}\) from resolve_re_qwot_alphas: by default different \(\alpha\) for phase 1, 2a, 2b, and 3 (e.g. stronger in phase 1, weaker in phase 3). Setting re_qwot_per_phase_schedule=False forces a single \(\alpha=\)re_qwot_penalty_weight. Optional re_qwot_adaptive_init_scale rescales all alphas from the initial spectral vs QWOT balance (clamped).

5.4 Ranking metric RMSE* (independent of phase alphas)

After the run, the code computes \(\mathrm{RMSE}^{\ast}=\sqrt{\mathrm{RMSE}_\mathrm{spec}^2 + \alpha_\mathrm{ref}\,\bigl(\mathrm{RMSE}_{\mathrm{QWOT}}^{\mathrm{raw}}\bigr)^2}\) with fixed re_ranking_alpha_ref (default 0.05). This is what re_parameter_batch.py sorts. Important: changing phase alphas changes the fit trajectory; \(\alpha_\mathrm{ref}\) does not change the optimiser — it only harmonises leaderboard scores.

6. Parametrisation of Dispersion Corrections

6.1 Spline knots on \(\Delta\mathrm{Re}\) for H and L materials

There are five wavelength knots per polarisation branch: fixed anchors at 1100, 2600, 3600, 4800 nm and an interior knot \(\lambda_2\) optimised in \([1500, 2100]\) nm by default. Amplitudes are bounded by a monotone PCHIP envelope on \(|\Delta\mathrm{Re}|(\lambda)\) scaled by re_envelope_scale (×0.5 tightens the corridor, ×1 uses the full tabulated envelope shape). Applying splines rebuilds corrected indices via re_apply_re_index_model before each spectrum call.

6.2 Substrate Cauchy extension (optional)

If enabled, the substrate index gains \(\Delta n_\mathrm{sub}(\lambda)=a_0+a_1(\lambda_\mathrm{ref}/\lambda)^2+a_2(\lambda_\mathrm{ref}/\lambda)^4\) with \((a_0,a_1,a_2)\) bounded, subject to a tube constraint \(|n_\mathrm{sim}-n_\mathrm{tab}|\le 0.05\) at every worker wavelength. Violations are pushed by a barrier penalty (weight RE_SUB_CAUCHY_BARRIER_SQRT_W). If the feasible set is empty, the worker falls back to a fixed tabulated substrate and logs a warning.

6.3 HL regularisation on \(\Delta\mathrm{Re}\) (not on substrate)

At each knot, a term \(\sqrt{w}\,(\Delta\mathrm{Re}_k / \mathrm{env}(\lambda_k))^2\) enters the cost (config stores \(\sqrt{w}\) as re_hl_delta_re_reg_sqrt_w). A dead zone on \(|\Delta\mathrm{Re}|\) (default 0.01) suppresses noise-fitting tiny wiggles. Setting \(\sqrt{w}=0\) disables this block.

6.4 Tikhonov smoothness on spline coefficients

Second-difference penalties along knot index stabilise non-physical oscillations between wavelengths; strength is re_spline_tikhonov_scale. This is distinct from the envelope (hard bound) and from HL (ratio-to-envelope).

7. REWorker Pipeline — Numerical Steps

Solver: Trust Region Reflective (scipy.optimize.least_squares with TRF) with tight RE_TRF_FTOL / RE_TRF_GTOL. Thickness bounds in phase 1 derive from RE_THICKNESS_SEARCH_RADIUS_PCT (default ±5%) around the workbook seed.

flowchart TB S[Seed ep0 from workbook] --> P1[Phase 1: TRF on thicknesses only] P1 --> M{Top-K merge if RMSE sum within rel tol} M --> P2a[Phase 2a: TRF on splines plus lambda2 — thicknesses fixed] P2a --> P2b[Phase 2b: joint TRF — ep plus splines plus lambda2 plus optional Cauchy theta] P2b --> P3{re_phase3_shake_rounds greater than 0?} P3 -->|yes| SH[Adaptive Gaussian shake on ep and splines then local TRF polish] P3 -->|no| OUT[Emit results plus RMSE star] SH --> OUT
Phase 1 — thickness multistart re_phase1_multistarts launches several TRF runs from dispersed initial thicknesses (LHS-style second starts). Candidates are sorted by RMSE∑; re_phase2_top_k keeps the best few for phase 2. If two candidates are within RE_PHASE2_TOP_K_MERGE_REL_TOL in RMSE∑, the list collapses to avoid duplicate joint work.
Phase 2a — spline prefit re_phase2_spline_prefit_maxiter caps TRF steps on the low-dimensional spline + \(\lambda_2\) problem only. Jacobian entries use forward finite differences on spline amplitudes (step RE_PHASE2_SPLINE_FD_STEP) and on \(\lambda_2\) (RE_PHASE2_LAM2_FD_STEP nm). Parallel FD across residual blocks is controlled by RE_PHASE2_FD_PARALLEL / RE_PHASE2_FD_MAX_WORKERS (0 → up to 8 workers). Prefit tolerances are relaxed by RE_PHASE2A_PREFIT_TOL_FACTOR so the joint phase receives a good warm start, not a fully converged subproblem.
Phase 2b — joint refinement Thickness derivatives are analytic where available; spline / \(\lambda_2\) / Cauchy parameters use the same FD machinery. Max iterations re_phase2b_maxiter. The residual vector stacks spectral blocks, Tikhonov rows, HL terms, substrate barrier violations, etc., into one least-squares problem — this is why iteration logs show many “FD residual blocks”.
Phase 3 — shake rounds re_phase3_shake_rounds applies stochastic perturbations to thicknesses and spline amplitudes; perturbation scales are adaptive via shake_sigmas_adaptive in certus_re_worker_utils.py: small global residual → larger exploration; large misfit → tighter shakes. Each round accepts improvements that lower RMSE∑ and can re-enter local TRF.

9. Reading the Logs (Science + Debugging)

  • RE context — \(\lambda\) grid extent, active target count, incidence, phase-1 thickness radius.
  • RE diag [initial …] / [fin phase …] — RMSE\(_\mathrm{spec}\), RMSE\(_\mathrm{QWOT}\), RMSE∑, and percentage split of \(\mathrm{RMSE}_\Sigma^2\) between spectral and \(\alpha\cdot\)QWOT².
  • Hint lines after diagnostics suggest whether to increase QWOT weight, tighten envelope, or check Excel QWOT metadata.
  • substrate Cauchy barrier — norm of tube violations; active constraints vs interior feasible points.

12. Operational Checklist

  • Reproducibility: Archive workbook, git commit, Python version, full cfg dict, and JSON batch output.
  • Fair comparison: When comparing pipeline runs, keep BATCH_WINNER_BASE identical — only vary multistarts / top-K / shakes.
  • Performance: If CPUs are oversubscribed, set OMP_NUM_THREADS=1 or reduce RE_PHASE2_FD_MAX_WORKERS.
  • Stopping: OS kill leaves no re_batch_*.json; prefer letting the budget expire for a clean summary.
