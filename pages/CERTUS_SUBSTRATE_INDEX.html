CERTUS-SUBSTRATE-INDEX

Bare-substrate spectra → $n(\lambda)$ (polynomial, Sellmeier, spline)

Module certus_substrate_index.py · Scientific Revision 2026.04.17

Executive Summary: This tool extracts the refractive index of an uncoated substrate from transmission (and related) spectral columns in Excel workbooks. It does not fit a film stack: it targets columns that describe the bare substrate only, using bilingual heuristics (FR/EN) on sheet and column headers (e.g. RNU, TNU, “substrate nu”, “bare sub”). For each valid trace, the app inverts the double-sided incoherent slab model to obtain $n(\lambda)$, then fits three dispersion laws in parallel—polynomial, Sellmeier (3-pole and catalogue-aware variants), and spline—and reports RMSE so you can pick the most stable law for your band. Optional Savitzky–Golay smoothing blends with the raw trace before inversion. Use this as the substrate reference before INDEX, RE, or METAL workflows.

1. Scope: Substrate Only

CERTUS-SUBSTRATE-INDEX is complementary to CERTUS-INDEX / INDEX-SPLINE: those modules infer film $n,k$ (and thickness) on a known substrate. Here the substrate itself is the unknown, inferred from measurements on the blank.

  • Included: parsing multi-sheet Excel, column detection, inversion $T \to n$, three-law fitting, export/plot comparison.
  • Excluded: multilayer design, global film optimization, database write-back into the main CERTUS material DB (results stay in the tool / export paths provided by the UI).

2. Column Detection & Hygiene

Headers are normalized (accents stripped, separators unified) and matched against include/exclude patterns so that coated stack or target columns are rejected while bare substrate spectroscopic tags are kept.

Tip: Use clear labelling (e.g. “TNU”, “RNU”, “substrate nu”, “bare substrate”) on the measurement sheet. Ambiguous names may be skipped or misclassified—inspect the interactive column picker after load.

3. From Transmission to $n(\lambda)$

For a thick transparent plate with incoherent multiple reflections, transmission is related to $n$ by the standard two-surface formula (air–substrate–air). The implementation follows the same photometric conventions as the rest of CERTUS (see Optical Theory Guide and Metrology for propagation of uncertainties on $T$).

$$ T = \frac{(1-R)^2}{1-R^2} = \frac{2n}{n^2+1} \quad \implies \quad n = \frac{1}{T} + \sqrt{\frac{1}{T^2} - 1} $$

This exact algebraic inversion assumes $k \approx 0$ (transparent regime) and normal incidence. The resulting $n(\lambda)$ is used as the target vector for the subsequent dispersion fits. You set λ min / λ max for the fit window; points outside can be greyed in previews so that edge noise does not dominate the Sellmeier fit.

  • Polynomial: flexible baseline in powers of $1/\lambda$ and $\lambda$. (Warning: This is a purely empirical, non-physical fit that diverges outside the measurement band and lacks resonant poles. Use only for narrow-band interpolation.)
  • Sellmeier (3-pole): physical dispersion form with tightened physical bounds:
    $$ n^2(\lambda) - 1 = \frac{B_1 \lambda^2}{\lambda^2 - L_1^2} + \frac{B_2 \lambda^2}{\lambda^2 - L_2^2} + \frac{B_3 \lambda^2}{\lambda^2 - L_3^2} $$
    Optimized via multistart least squares + L-BFGS-B polish (log-reparameterization is disabled in favor of strict linear bounds). Catalogue priors from SELLMEIER_COEFFS_BY_ID can seed the search when the material name hints a known glass.
  • Spline: non-parametric smooth representation for comparison RMSE.
  • Sellmeier full auto: hides advanced time/iteration budgets; uncheck to tune DE/L-BFGS-B / least_squares evaluation limits for difficult bands.

5. Workflow in the GUI

  1. Load Data — .xlsx / .xls; interactive mapping if needed (open_measurement_excel_interactive).
  2. Set fit range and optional preprocessing (dynamic Savitzky–Golay blend).
  3. Run Calc Substrate Index (3 laws); inspect table RMSE and plots.
  4. Copy or export results for use as substrate $n(\lambda)$ in other modules.

6. Good Practice

  • Prefer spectral regions where the substrate is transparent ($k \approx 0$); strong absorption invalidates the inversion model.
  • Cross-check Sellmeier against supplier data or handbook when publishing.
  • For uncertainty budgets (non-linearity, thickness of plate), see the Metrology protocol document.
