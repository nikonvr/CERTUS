First design · a 50/50 beam splitter

Open the supplied 50/50 design file. Its target is constant 50% transmission from 400 to 1200 nm at normal incidence. The model uses lossless materials and excludes the rear face of the glass.

  1. Check the target row. Both endpoint values are 0.5 and the weight is 1. The example requests 108 wavelength samples per target. The target band spans 400–1200 nm. The separate 500 nm setting is the reference wavelength for layer thickness.
  2. Check the starting stack. There are 34 variable layers alternating H and L on glass of index 1.52. Every row starts at 0.9 QWOT. The first H layer (index 2.35) is 47.87 nm thick, and the next L layer (index 1.45) is 77.59 nm thick. These values let you check the unit conversion after loading.
  3. Inspect the baseline. Select Evaluate (Ctrl+E) to draw the starting spectrum. Follow its departures from 0.5 across the band. The optimization changes the layer thicknesses to reduce those departures.
  4. Run and compare. Select PGLOBAL (global) to launch the full workflow. For this normal-incidence file the default global search is memetic. Check the restored layer count against the 34-layer limit, then evaluate the final stack on the same fine grid before comparing it with the published campaign values.

Set up a design

  1. Choose the materials and substrate. The complex index follows the Macleod convention $\hat n=n-ik$ with $k\ge 0$. Set the rear-face calculation and rear coating to match the part.
  2. Set the reference wavelength $\lambda_0$ and the substrate-first sequence. The native thickness field uses $4n_4d/\lambda_0$, with $n_4$ the material index at 400 nm. Mark the layers that the optimizer may vary and check the physical thicknesses in nm.
  3. Enter active target bands, their endpoint values and relative weights. DESIGN interpolates a ramp linearly in wavelength between its endpoints. Normal-incidence rows specify transmission as a fraction from 0 to 1. In oblique mode each row specifies an angle in degrees, s or p polarization, and R or T. To constrain both polarizations, enter a separate target for each. Each row then contributes its own error.
  4. Set the layer and optical-thickness constraints, choose the optimization grid, and inspect the initial spectrum before starting the global workflow or a local fit.

Reproducible inputs are available in the bundled design or in the 50/50 example above.

  • Review the cleanup log for fixed layers below the requested floor. Oblique runs and files with final_cleanup: false follow the legacy 5 nm rule.

Optimization and wavelength sampling

Each memetic child inherits parts of its parents' thickness vectors and receives a perturbation. Local polishing evaluates the child before it can replace a population member. Levenberg–Marquardt uses a weighted residual Jacobian in the supported normal-incidence path, with a cost agreement check against the production objective. The separate PGLOBAL branch samples and clusters candidates before refining representatives.

Robustness-aware search

DESIGN can favor candidate stacks whose spectra are less sensitive to independent layer-thickness errors. This optional criterion acts during the memetic population search. It complements Robust N, which compares saved layer-count candidates, and Spectral Monte Carlo, which tests a finished stack under simulated errors.

Activate population selection under thickness errors

Save the design, then merge the following settings into its existing optimization block and reload it. Older example files use the alias optim; update that existing block rather than creating a second one. The robustness setting is configured through the design file.

"optimization": {
    "memetic_polisher": "lbfgs_then_lm",
    "memetic_robust_sigma_nm": 1.0
}

Here 1.0 means an independent physical-thickness error with a standard deviation of 1 nm for each variable layer. Set memetic_robust_sigma_nm to 0 to use nominal population ranking, which remains the default. Choose the positive value from the intended deposition process rather than from the desired spectral score.

Criterion and supported configurations

If $r(d)$ is the weighted residual vector and $J=\partial r/\partial d$ its Jacobian with respect to variable physical thicknesses in nm, the population ranks locally polished candidates by

$$C_{\mathrm{selection}}(d)=C_{\mathrm{nominal}}(d) +\sigma_d^2\lVert J(d)\rVert_F^2.$$

The added term is the Gauss–Newton estimate of the mean-square sensitivity to independent, zero-mean thickness errors with equal variance. Each local descent still minimizes the nominal merit; the population then favors less sensitive solutions among the minima it finds. Subsequent local refinement and cleanup also use the nominal merit. The final displayed RMSE is nominal, so evaluate the exported final stack under errors as well.

  • The criterion requires the normal-incidence, real-index fast context and an available lm or lbfgs_then_lm polisher. The residuals must reproduce the production merit, and the layer bounds must respect the active thickness floor.
  • If these conditions fail, the log explains the fallback and warns that the robustness setting was ignored. Check the optimization log before interpreting a run as robust.
  • This selection model uses equal absolute errors on variable layers. Correlated deposition errors, material-index uncertainty and large nonlinear perturbations require additional assessment. The Jacobian criterion is a local approximation.

Validate and choose the final structure

  1. Compare nominal and robustness-aware runs with matching seeds, targets, bounds and budgets. Evaluate the exported stacks on the same independent wavelength grid.
  2. Use Spectral Monte Carlo with a fresh seed and the intended absolute, relative and optical-thickness error settings. Report nominal RMSE, RMS under errors, 95th percentile, mean of the worst 5% and simulated yield when a limit is specified.
  3. Use Robust N after an optimization to rank the available Pareto records by their second-order estimated RMSE under the configured error model. Its log recommends a layer count; inspect and validate that candidate before export.

Each insertion triggers a 3-step cycle: optimize → cleanup → evaluate. Safety Guards: Stagnation detector (3 cycles without growth or RMSE improvement → abort), Needle failure limit (3 consecutive failed insertions → abort), MAX_LAYERS cap. All abort paths clean workflow state to prevent stale flags.

2. Why starting thicknesses matter

Changing a layer’s thickness changes the phase accumulated in that layer. Different thickness vectors can place interference peaks at similar wavelengths. A bounded local polish may therefore converge to different solutions from different starting stacks. The number of search coordinates is the number of variable layers. Fixed layers still contribute to the optical response.

3. How PGLOBAL chooses local starts

PGLOBAL samples thickness vectors inside the bounds, evaluates their merit, then keeps the lower-cost part of each batch. Clustering limits repeated local searches near promising starts. The worker retains the best result it finds within its evaluation and stopping limits.

3.1 Critical Clustering Distance

The algorithm groups sample points into "basins of attraction" to avoid redundant local optimizations. The critical distance threshold $d_c$ is derived from the statistical theory of closest points in a Poisson process:

$$ d_c = \frac{1}{\sqrt{\pi}} \left( \Gamma\left(1 + \frac{D}{2}\right) \cdot \alpha \cdot \frac{\ln N}{N} \right)^{1/D} $$
  • $D$ is the number of variable thicknesses in the global search.
  • $N$ is the cumulative evaluation count supplied to the clustering step, with a minimum of two.
  • $\alpha$ sets the clustering radius. The implementation caps $d_c$ at $\sqrt{D}/2$, half the diagonal of the normalized search space.
  • $\Gamma$: The Gamma function, extending factorial to real numbers.

3.2 Clustering Kernel

The distance is measured after dividing the thickness difference on each variable layer by that layer’s permitted thickness range. A 1 nm difference therefore counts more for a tightly bounded layer than for one with a wide range. For variable-layer bounds $[l_j,u_j]$, the comparison uses

$$ r(\mathbf{x},\mathbf{y})^2 = \sum_{j=1}^{D}\left(\frac{x_j-y_j}{u_j-l_j}\right)^2 . $$

A candidate is screened out when a prior seed or another point in its batch has both strictly lower cost and $r < d_c$. Points that pass are eligible for a local search. This distance test saves evaluations when nearby starts are likely to converge to similar designs.

4. Transfer Matrix Method (TMM)

4.1 Characteristic Matrix (Macleod Convention)

CERTUS uses the Macleod convention with complex refractive index $\hat{n} = n - ik$ (k > 0 for absorbing materials) and factor +1j in the off-diagonal elements:

$$ \mathbf{M}_j = \begin{pmatrix} \cos\phi_j & \frac{+i\sin\phi_j}{\hat{n}_j} \\ +i\hat{n}_j\sin\phi_j & \cos\phi_j \end{pmatrix}, \qquad \phi_j = \frac{2\pi}{\lambda}\hat{n}_j d_j $$

4.2 System Matrix and Observables

The total system matrix is built by pre-multiplication in Air→Substrate order:

$$ \mathbf{M}_{sys} = \mathbf{M}_{N} \cdot \mathbf{M}_{N-1} \cdots \mathbf{M}_{1} $$

Transmittance for normal incidence ($n_{inc} = 1$, $n_{exit} = n_{sub}$):

$$ T = \frac{4\,\text{Re}(n_{sub})}{|m_{00} + n_{sub}\,m_{01} + m_{10} + n_{sub}\,m_{11}|^2} $$

4.3 Incoherent Backside Correction

For glass substrates (~1 mm), the back surface reflects incoherently. CERTUS uses a dual-matrix approach:

  • Forward matrix $\mathbf{F}$ (pre-multiply Air→Sub): extracts $T_{fwd}$ and $R_{fwd}$.
  • Reverse matrix $\mathbf{R}$ (post-multiply Sub→Air): extracts $R_{back}$.
$$ T_{total} = \frac{T_{fwd} \cdot T_{ext}}{1 - R_{back} \cdot R_{ext}}, \qquad R_{ext} = \left(\frac{n_{sub} - 1}{n_{sub} + 1}\right)^2 $$

When the substrate absorbs ($\hat n = n - ik$, $k > 0$), it is a plate of thickness $D$ that loses part of the flux on each pass (Beer–Lambert). With $\tau$ the flux left after one pass, the same formula holds with $T_{ext} \to T_{ext}\,\tau$ and $R_{ext} \to R_{ext}\,\tau^2$:

$$ \tau = e^{-4\pi\,|k|\,D\,/\,(\lambda \cos\theta)}, \qquad T_{total} = \frac{T_{fwd} \cdot T_{ext}\,\tau}{1 - R_{back} \cdot R_{ext}\,\tau^2} $$

$\tau = 1$ is the lossless plate above; $\tau = 0$ is the semi-infinite absorber (nothing comes back from the back side). The two are the ends of one formula, so the result is continuous in $k$. DESIGN and STRAT do not ask for $D$: it defaults to 1 mm.

5. Analytic Gradient (The Adjoint Method)

To refine the best clusters, CERTUS uses the L-BFGS-B algorithm. This requires the gradient vector $\nabla_{\mathbf{d}} \text{MSE}$. Calculating this numerically (Finite Differences) requires $2N$ matrix evaluations per step ($O(N^2)$). CERTUS implements an Analytic Gradient ($O(N)$) using the Adjoint Matrix method.

5.1 Forward-Backward Propagation

We decompose the total transfer matrix $\mathbf{M}_{total}$ for a stack of $N$ layers. For any layer $j$, we define:

$$ \mathbf{M}_{before}[j] = \prod_{k=0}^{j-1} \mathbf{M}_k \quad \text{(Substrate to Layer } j)$$ $$ \mathbf{M}_{after}[j] = \prod_{k=N}^{j+1} \mathbf{M}_k \quad \text{(Air to Layer } j)$$

Both products are computed in a single $O(N)$ scan and cached.

5.2 Exact Derivative

The derivative of the total matrix with respect to thickness $d_j$ uses the matrix chain rule:

$$ \frac{\partial \mathbf{M}_{total}}{\partial d_j} = \mathbf{M}_{after}[j] \cdot \frac{d\mathbf{M}_j}{d d_j} \cdot \mathbf{M}_{before}[j] $$
$$ \text{MSE} = \frac{\sum_{k\in V} w_k\,[S_{calc}(\lambda_k)-S_{target}(\lambda_k)]^2}{\sum_{k\in V} w_k}, \qquad \frac{\partial \text{MSE}}{\partial d_j} = \frac{2}{\sum_{k\in V} w_k} \sum_{k\in V} w_k\,[S_{calc}(\lambda_k)-S_{target}(\lambda_k)] \frac{\partial S_{calc}(\lambda_k)}{\partial d_j} $$

Where $\frac{\partial S_{calc}}{\partial d_j}$ is extracted directly from the components of $\frac{\partial \mathbf{M}_{total}}{\partial d_j}$. This explicit Jacobian $\nabla_{\mathbf{d}} \text{MSE}$ is what feeds the L-BFGS-B quasi-Newton step. Here $V$ contains valid weighted target points. The sum of their weights normalizes both the spectral cost and its gradient. For the front-only and backside paths, a positive layer thickness below the configured minimum also incurs a quadratic penalty. L-BFGS-B receives the derivative of that penalty for each variable layer.

flowchart LR A[Trial layer thicknesses] --> B{Backside calculation enabled?} B -->|No| C[Front-stack TMM and analytic sensitivities] B -->|Yes, bare or coated back| D[Backside oblique TMM and analytic sensitivities] C --> E[Keep valid target points and their weights] D --> E E --> F[Sum weighted squared errors and weighted derivatives] F --> G{Sum of valid weights sufficient?} G -->|Yes| H[Cost: error sum / weight sum; gradient: 2 x derivative sum / weight sum] G -->|No| I[Large penalty cost; zero gradient] H --> J[L-BFGS-B step inside thickness bounds] I --> J

The derivative of a single layer matrix $\mathbf{M}_j$ is analytically simple:

$$ \frac{d\mathbf{M}_j}{d d_j} = \frac{2\pi \hat{n}_j}{\lambda} \begin{pmatrix} -\sin\phi_j & \frac{+i\cos\phi_j}{\hat{n}_j} \\ +i\hat{n}_j\cos\phi_j & -\sin\phi_j \end{pmatrix} $$
Performance: This allows calculating the gradients for ALL $N$ layers in a single forward + backward pass, resulting in a 50×–100× speedup compared to numerical differentiation. All gradient kernels are JIT-compiled via Numba in Float64/Complex128.

5.3 Bounds for absorbing layers

Before global, local or healing optimisation, optim_opaque_thickness_limits computes a per-layer upper thickness from the shortest wavelength and the largest absolute imaginary index on the grid. For an absorbing layer it caps the mode's upper bound at $0.99\times700\lambda_{min}/(2\pi k_{max})$ nm, one percent below the phase-overflow threshold. A nonabsorbing layer has no additional cap. The cap is applied without moving a mode's lower bound; when that lower bound permits it, this keeps the optimiser inside the range accepted by the existing physics kernels, whose guard otherwise returns $(R,T)=(0,0)$ beyond that threshold.

flowchart TD A[Variable layers and wavelength grid] --> B[Build usual mode bounds: global, local or healing] A --> C[For each layer: maximum absolute imaginary index and minimum wavelength] C --> D{Absorbing layer?} D -->|No| E[Infinite opacity limit] D -->|Yes| F[Limit = 0.99 x 700 x shortest wavelength / 2 pi x maximum k] B --> G[Cap each upper bound by its layer opacity limit] E --> G F --> G G --> H[Bounded global search or local L-BFGS-B]

On the measured infrared metal case ($n=0.02-60i$, 8–12 µm), this removed a global upper bound above 100 µm; bounds for a nonabsorbing layer were bit-identical. The corrected backside gradient matched finite differences to $10^{-5}$ in its regression cases.

6. Smart Cleanup & Two-Phase Healing

After global optimization, some layers may converge to negligible thicknesses (< 1 nm). Smart Cleanup removes these and merges adjacent layers of identical materials. This topology change alters the design space, potentially trapping the solution in a suboptimal basin.

6.1 Smart Cleanup

smart_cleanup(update_target=False) 1. Remove all layers with $d < 1.0$ nm (conservative threshold).
2. Merge adjacent layers of the same material: $d_{merged} = d_i + d_{i+1}$.
3. update_target=False: preserve original layer count target
  so the Needle can grow back any removed layers.

6.2 Two-Phase Healing

If cleanup removed layers, the design is healed in two guaranteed phases. The local descent is never skipped, even if the restricted global finds a good solution.

Phase 1 — Restricted Global (mode = 'healing') PGLOBAL search within material-aware bounds:
$$ \Delta d_j = \frac{\lambda_0}{10\, n_j(\lambda_0)} \quad \text{(~40% of QWOT)} $$ Bounds per layer: $[d_j - \Delta d_j,\; d_j + \Delta d_j]$
Config: 1000 × scale samples/iter, 10 iterations, 20 clusters max, 50k evals.
Explores basins in the vicinity of the current solution after topology change.
Phase 2 — Local Polish (mode = 'local') L-BFGS-B within $\pm 2$ nm bounds, using the analytic gradient.
Converges precisely within the best basin found by Phase 1.
This phase is always executed, guaranteeing that the local descent is not missed.
flowchart TD A["Current multilayer design"] --> B["Remove layers thinner than 1 nm"] B --> C["Merge adjacent identical materials"] C --> D{"Were layers removed?"} D -->|Yes| E["Restricted PGLOBAL around remaining thicknesses"] E --> F["L-BFGS-B local polish within 2 nm bounds"] D -->|No| G["Keep cleaned design"] F --> H["Return healed design"]
Excursion Example ($\lambda_0 = 550$ nm):
SiO₂ ($n = 1.46$): $\Delta d = 37.7$ nm  |  TiO₂ ($n = 2.30$): $\Delta d = 23.9$ nm  |  Ta₂O₅ ($n = 2.10$): $\Delta d = 26.2$ nm
The excursion is physically motivated and material-dependent, unlike a fixed percentage.

7. Needle Method & Overshoot-Prune Strategy

When the layer count is below the user's target (after cleanup removed layers), the Needle Method (Tikhonravov) is activated to grow the structure. It calculates the topological derivative $P(z)$ across the optical thickness of the stack:

$$ P(z) = \frac{\partial \text{Merit}}{\partial d_{new}} \bigg|_{d_{new} \to 0} $$

If $P(z)$ is strongly negative at position $z$, inserting a zero-thickness layer (mathematical needle) of the alternate material at position $z$ will decrease the merit function.

7.1 Needle Insertion Cycle (3 Steps)

Per-insertion cycle Step 1 (Optim): Insert needle at $z^*$ by splitting the host layer. Run L-BFGS-B on the $(N+2)$-layer stack (left + needle + right).
Step 2 (Cleanup): Smart cleanup — remove thin layers, merge adjacent identical. If layers removed, re-optimize.
Step 3 (Evaluate): Check RMSE improvement vs pre-insertion value. Require > 1% improvement to count as "successful." If stagnation detected 3× consecutively → abort.

7.2 Overshoot & Prune Strategy

On first layer deficit, the system does not grow exactly to the target. Instead, it temporarily overshoots by +20% to enrich the design space, then prunes back:

Overshoot & Prune Algorithm 1. Set temporary target: $N_{overshoot} = \min(\lceil 1.20 \times N_{target} \rceil,\; N_{max})$, with a minimum of $N_{target} + 2$.
2. Grow via iterative Needle insertions until $N_{overshoot}$ is reached.
3. Prune one layer at a time (thinnest first):
  a. Identify thinnest layer: $j = \arg\min_i d_i$.
  b. Remove layer $j$ from the stack.
  c. Merge any newly-adjacent identical materials.
  d. Repeat until $\text{count} \leq N_{target}$.
4. Final L-BFGS-B polish on the pruned stack.
flowchart TD A["Layer count below target"] --> B["Set temporary overshoot target"] B --> C["Locate favorable needle position from topological derivative"] C --> D["Insert alternate material and run local polish"] D --> E["Remove thin layers and merge identical neighbors"] E --> F{"RMSE improved by more than 1 percent?"} F -->|No| G{"Three consecutive stagnations?"} G -->|Yes| H["Stop needle growth"] G -->|No| C F -->|Yes| I{"Temporary layer target reached?"} I -->|No| C I -->|Yes| J["Prune thinnest layer one at a time, merging neighbors"] J --> K["Final local polish at target count"]
Why one-at-a-time pruning? In alternating H/L stacks, removing one layer makes its two neighbours (same material) adjacent, triggering a merge. This gives a net reduction of 2 layers per prune step. Batch removal would overshoot the pruning target. The +20% overshoot compensates for this effect and provides enough extra layers to explore a richer design space before converging to the final topology.

8. Spectral merit and colour analysis

8.1 Spectral RMSE

$$ \text{RMSE} = \sqrt{\frac{\sum_j w_j \left(S_{calc}(\lambda_j) - S_{target}(\lambda_j)\right)^2}{\sum_j w_j}} $$

On the normal transmission path, $w_j$ combines the target weight and the trapezoidal width in $\ln\lambda$. For a grid over disjoint targets, the endpoints receive the widths inside their own bands. The gap between bands contributes no width. Reflection or transmission in the oblique path is selected per target and evaluated in groups of equal angle and polarization.

8.2 Colour Analysis (Monte Carlo)

DESIGN does not optimize towards a colour: colour enters only an analysis of the current design. Its front-side reflectance at normal incidence, without the rear face, is computed from 380 to 780 nm every 5 nm. The tristimulus values $X, Y, Z$ follow from the CIE 1931 2° colour-matching functions and the D65 illuminant, scaled so that a perfect reflector has $Y = 100$, and the CIELAB coordinates $(L^*, a^*, b^*)$ from the D65 white point. The analysis then draws $N$ perturbed designs (200 by default), each layer thickness shifted by an independent Gaussian error of standard deviation $\sigma$ (2 nm by default; a negative thickness is set to zero), with a fixed seed. It reports the nominal $(L^*, a^*, b^*)$, its sRGB rendering, and the mean and standard deviation over the samples of the CIEDE2000 difference $\Delta E_{00}$ to the nominal colour:

$$ \Delta E_{00} = \sqrt{ \left(\frac{\Delta L'}{k_L S_L}\right)^2 + \left(\frac{\Delta C'}{k_C S_C}\right)^2 + \left(\frac{\Delta H'}{k_H S_H}\right)^2 + R_T \frac{\Delta C'}{k_C S_C} \frac{\Delta H'}{k_H S_H} } $$
