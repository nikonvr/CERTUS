CERTUS-INDEX

Advanced Tauc-Lorentz-Urbach Characterization Engine

Scientific Revision Pro 2026.04.17 — Complete Algorithm Documentation

Executive Summary: CERTUS-INDEX is a high-level scientific tool for extracting the optical constants ($n, k$) of semiconductors and dielectrics over the full VIS–IR spectral range (300–5000 nm). It combines a rigorous Tauc-Lorentz-Urbach (TLU) global fit (Kramers-Kronig consistent) with an optional Spline Refinement pipeline that achieves RMSE < 0.005 on real-world data. When the spectrum extends beyond 2500 nm, a two-stage pipeline runs automatically: TLU is fitted on 1000–2200 nm only, then IR Global Model (Phase 2) refines $n$, $k$ over the full range: Stage 0–2 (Sellmeier 5p + empirical k 8p with PGlobal + L-BFGS-B), then Phase 2.3 (spline $k$ in $\log k$ with knot deduction, Pass 1 + Pass 2, optional knot reduction 8→4), then Phase 2.1 (90% T / 10% R refinement from the spline result). The optional Spline stage (spectrum ≤2500 nm) uses pointwise IR inversion, L-BFGS-B knot optimization, and a final joint re-optimization of thickness, knot positions, and $n$/$k$ values.

1. The Scientific Problem: Absorption & Physical Causality

Standard "transparent" models fail near the bandgap of materials (e.g., TiO2, ZnO). Empirical fitting of $k$ often violates the Kramers-Kronig (KK) relations.

CERTUS-INDEX solves this by fitting the parameters of the dielectric function where $\epsilon_1$ is derived analytically from $\epsilon_2$ via KK integration. This allows accurate modeling of Interband Transitions ($E_g$) and the exponential "Urbach Tail" ($E_u$) representing defect states.

2. Theoretical Foundation: The TLU Model

The Tauc-Lorentz-Urbach model combines Tauc-Lorentz oscillator physics above the band gap with an Urbach exponential tail below, ensuring smooth transitions and physical causality.

2.1 Imaginary Dielectric Function $\epsilon_2(E)$

The imaginary part of the dielectric function describes optical absorption. The TLU model uses a piecewise definition:

$$ \epsilon_2(E) = \begin{cases} \frac{A \, E_0 \, C \, (E - E_g)^2}{E \left[(E^2 - E_0^2)^2 + C^2 E^2\right]} & \text{for } E > E_g \quad \text{(Tauc-Lorentz)} \\ A_{\text{urb}} \cdot \exp\left(\frac{E - E_g}{E_u}\right) & \text{for } E \le E_g \quad \text{(Urbach Tail)} \end{cases} $$
Physical Origin:
  • Tauc-Lorentz regime ($E > E_g$): Interband transitions. The $(E - E_g)^2$ term reflects the parabolic joint density of states (JDOS) near the band edge in amorphous semiconductors.
  • Urbach regime ($E \le E_g$): Sub-bandgap absorption due to localized tail states from structural disorder, dangling bonds, or thermal fluctuations. The exponential shape is universal across disordered materials.

2.2 Continuity Condition at $E = E_g$

The Tauc-Lorentz function and its first derivative both vanish exactly at $E = E_g$ (since the numerator contains $(E - E_g)^2$). Therefore, direct function or slope matching yields $A_{\text{urb}} = 0$, which is physically undesirable.

In practice, CERTUS-INDEX evaluates $\epsilon_2^{TL}$ at a slight offset $E_g + \delta$ (with $\delta = 0.01$ eV) and uses this finite value as the Urbach matching amplitude:

$$ A_{\text{urb}} = \epsilon_2^{TL}(E_g + \delta) = \frac{A \, E_0 \, C \, \delta^2} {(E_g + \delta)\left[((E_g+\delta)^2 - E_0^2)^2 + C^2 (E_g+\delta)^2\right]} $$

The Urbach tail then reads $\epsilon_2^{Urb}(E) = A_{\text{urb}} \cdot \exp\!\left(\frac{E - E_g - \delta}{E_u}\right)$ for $E \leq E_g$, ensuring a smooth, non-zero sub-gap tail. This approach preserves the 6 independent parameters ($A, E_0, C, E_g, E_u, \epsilon_\infty$).

2.3 Real Dielectric Function $\epsilon_1(E)$ — Kramers-Kronig Transform

Causality (the response cannot precede the excitation) imposes a strict mathematical relationship between $\epsilon_1$ and $\epsilon_2$:

$$ \epsilon_1(E) = \epsilon_\infty + \frac{2}{\pi} \, \mathcal{P} \int_0^\infty \frac{\xi \, \epsilon_2(\xi)}{\xi^2 - E^2} \, d\xi $$

For the Tauc-Lorentz model, Jellison & Modine (1996) derived a closed-form analytic solution, avoiding numerical integration entirely. The full expression is:

$$ \epsilon_1^{TL}(E) = \epsilon_\infty + \frac{A E_0 C}{\pi \zeta^4} \left\{ - \frac{E^2 + E_g^2}{E} \ln\left| \frac{E_g - E}{E_g + E} \right| + 2E_g \ln\left( \frac{|E_g^2 - E^2|}{\sqrt{(E_0^2 - E_g^2)^2 + C^2 E_g^2}} \right) + \frac{a_{\ln}}{2\alpha E_0} \ln\left( \frac{E_0^2 + E_g^2 + \alpha E_g}{E_0^2 + E_g^2 - \alpha E_g} \right) - \frac{a_{\tan}}{C E_0^2} \left[ \pi - \arctan\left(\frac{2E_g + \alpha}{C}\right) - \arctan\left(\frac{2E_g - \alpha}{C}\right) \right] + \frac{4E_g}{\alpha C} (E^2 - \gamma^2) \left[ \frac{\pi}{2} - \arctan\left(\frac{2(E_g^2 - \gamma^2)}{\alpha C}\right) \right] \right\} $$

where the auxiliary parameters are defined as:

$$ \alpha = \sqrt{4 E_0^2 - C^2}, \quad \gamma = \sqrt{E_0^2 - \frac{C^2}{2}}, \quad \zeta^4 = (E^2 - E_0^2)^2 + C^2 E^2 $$ $$ a_{\ln} = (E_g^2 - E_0^2)E^2 + E_g^2 C^2 - E_0^2(E_0^2 + 3E_g^2) $$ $$ a_{\tan} = (E^2 - E_0^2)(E_0^2 + E_g^2) + E_g^2 C^2 $$

Implementation note: CERTUS uses a Numba JIT-compiled implementation (epsilon1_TL_analytic) ensuring evaluation in $\sim$10 µs per wavelength point.

2.4 Urbach Tail Contribution to $\epsilon_1$

For the sub-bandgap Urbach region, the KK integral yields an additional term:

$$ \epsilon_1^{Urb}(E) = \frac{2 A_{\text{urb}} E_u}{\pi} \cdot \text{Re}\left[ e^{(E_g - i E)/E_u} \cdot E_1\left(\frac{E_g - i E}{E_u}\right) \right] $$

where $E_1(z)$ is the exponential integral function. The total real dielectric function is:

$$ \epsilon_1(E) = \epsilon_1^{TL}(E) + \epsilon_1^{Urb}(E) $$

2.5 Conversion to Optical Constants $(n, k)$

From the complex dielectric function $\tilde{\epsilon} = \epsilon_1 + i\epsilon_2$, the refractive index and extinction coefficient are:

$$ n = \sqrt{\frac{\sqrt{\epsilon_1^2 + \epsilon_2^2} + \epsilon_1}{2}}, \quad k = \sqrt{\frac{\sqrt{\epsilon_1^2 + \epsilon_2^2} - \epsilon_1}{2}} $$

2.7 Micro-Macro Connection: Polarizability and Optical Constants

The TLU model fundamentally connects the microscopic response of the material to its macroscopic optical properties. Under the action of an external electric field $E(\omega)$, the electrons of the material oscillate, creating a macroscopic polarization $P(\omega)$:

$$ P(\omega) = \epsilon_0 \chi(\omega) E(\omega) $$

Where $\chi(\omega)$ is the electric susceptibility, directly related to the complex dielectric function $\tilde{\epsilon}(\omega) = 1 + \chi(\omega) = \epsilon_1(\omega) + i\epsilon_2(\omega)$. The optical constants $(n, k)$ that the model aims to extract are simply the expression of light propagation modified by this dipolar response: the refractive index $n$ captures the phase delay caused by polarization, while the extinction coefficient $k$ reflects energy dissipation (absorption) due to the phase lag between the field and the electronic response.

3. Alternative Dispersion Models and Metallic Extensions

Although the TLU model is optimal for amorphous semiconductors and dielectrics with a band gap, CERTUS recognizes the mathematical need for other formalisms to handle additional material classes, notably metals and phononic crystals.

3.1 The Drude Model (Free Electrons)

Essential for modeling the infrared (IR) and near-infrared (NIR) response of noble metals (Gold, Silver, Copper) or transparent conductors (ITO, ZnO:Al). Unlike dielectrics, conduction-band electrons are not bound to a specific atom.

$$ \tilde{\epsilon}_{Drude}(E) = \epsilon_\infty - \frac{E_p^2}{E^2 + i\Gamma_D E} $$
  • $E_p$ (Plasma frequency): Proportional to the free-electron density. Determines the cut-off frequency below which the metal becomes highly reflective.
  • $\Gamma_D$ (Damping / Collision rate): Inverse of the electronic relaxation time ($\tau$). Represents energy dissipation via collisions (phonons, impurities).

3.2 The Lorentz Model (Harmonic Oscillators)

Used to model discrete high-energy interband transitions or phononic resonances in the far infrared. It assumes electrons are bound to their nucleus by a restoring (spring-like) force.

$$ \tilde{\epsilon}_{Lorentz}(E) = \frac{A_L E_{0L}^2}{E_{0L}^2 - E^2 - i\Gamma_L E} $$

3.3 The Drude-Lorentz Model (Real Metals in the Visible)

In the visible range, metals such as Gold and Copper exhibit strong coloration caused by interband absorption (typically from d-bands to the Fermi level). The complete response requires combining the Drude free-electron conductivity (dominant at low energy) with Lorentz oscillators:

$$ \tilde{\epsilon}(E) = \tilde{\epsilon}_{Drude}(E) + \sum_{j} \tilde{\epsilon}_{Lorentz, j}(E) $$

3.4 Classical Reference Models

  • Cauchy: Empirical model ($n(\lambda) = A + B/\lambda^2 + C/\lambda^4$) strictly reserved for transparent dielectrics far from any absorption edge ($k=0$). Not causal.
  • Sellmeier: Physical model ($n^2(\lambda) = 1 + \sum \frac{B_i \lambda^2}{\lambda^2 - C_i}$) based on undamped Lorentz oscillators ($\Gamma=0$). Excellent for glass substrates in their transparency window.

3.5 The Modified Forouhi-Bloomer Model (mFB)

The Forouhi-Bloomer (FB) model, introduced in two seminal papers (Forouhi & Bloomer, Phys. Rev. B, 34(10):7018, 1986 for amorphous materials; Phys. Rev. B, 38(3):1865, 1988 for crystalline semiconductors), provides an analytical expression for the complex refractive index $\tilde{n}(E) = n(E) - ik(E)$ directly in terms of physically meaningful band-structure parameters.

Original Formulation

The imaginary part of the refractive index $k(E)$ is modeled as a sum of $q$ oscillator terms, each representing an optical transition:

$$ k(E) = \begin{cases} \displaystyle\sum_{i=1}^{q} \frac{A_i \left(E - E_{g}\right)^2}{E^2 - B_i E + C_i} & E > E_g \\ 0 & E \leq E_g \end{cases} $$

The real part $n(E)$ is obtained analytically via the Kramers-Kronig (KK) principal value integral:

$$ n(E) = n(\infty) + \sum_{i=1}^{q} \frac{B_{0,i}\, E + C_{0,i}}{E^2 - B_i E + C_i} $$

where the auxiliary coefficients $B_{0,i}$ and $C_{0,i}$ are derived from the Kramers-Kronig integration over the full energy axis ($0$ to $\infty$), yielding the closed-form expressions (Forouhi & Bloomer, Phys. Rev. B 34, 7018, 1986, Eqs. 4–5):

$$ B_{0,i} = \frac{A_i}{Q_i} \left( -\frac{B_i^2}{2} + E_g B_i - E_g^2 + C_i \right), \quad C_{0,i} = \frac{A_i}{Q_i} \left( (E_g^2 + C_i)\frac{B_i}{2} - 2 E_g C_i \right) $$

where $Q_i = \sqrt{4C_i - B_i^2}$. The constraint $B_i^2 - 4C_i < 0$ ensures complex poles (damped oscillators with finite lifetime).

Parameter Physical Meaning
$E_g$ (eV) Optical band gap: onset energy for interband transitions
$A_i$ (—) Oscillator strength of transition $i$ (dimensionless factor)
$B_i$ (eV) Twice the real part of the complex pole energy: $B_i = 2\,\text{Re}(E_{pole})$
$C_i$ (eV²) Squared modulus of the complex pole: $C_i = |E_{pole}|^2$
$n(\infty)$ High-frequency refractive index (contributions from transitions above the modeled range)

Limitations of the Original Model and Key Modifications

Subsequent analyses (Jellison & Modine, Appl. Phys. Lett. 69(3):371, 1996) identified several shortcomings of the original FB formulation:

  • KK non-compliance at $E_g$: The piecewise definition of $k(E)$ with a hard cutoff at $E_g$ introduces a discontinuity in the first derivative, making the strict KK relationship only approximately satisfied. This was the primary motivation for the Tauc-Lorentz (TL) model, which uses a smoother Tauc joint-density-of-states factor $(E - E_g)^2 / E$ rather than $(E - E_g)^2$ alone.
  • Sum-rule violation: The original FB model does not rigorously satisfy the oscillator-strength sum rule $\int_0^\infty \epsilon_2(\omega)\,d\omega = \text{const}$, which is a consequence of causality.
  • Non-negative $k$ constraint: In multi-oscillator configurations, the sum of terms can produce negative values of $k(E)$ in spectral windows between oscillators.

The Modified Forouhi-Bloomer (mFB) model addresses these issues through several refinements documented in a series of publications by Likhachev (J. Appl. Phys. 118:195107, 2015; Thin Solid Films 589:712, 2015; J. Appl. Phys. 119:085706, 2016):

  • 1. The Divergence Problem and KK Correction

    Because the original FB model scales as $k(E) \sim A_i$ as $E \to \infty$ (it does not vanish), its rigorous KK integral from $E_g$ to $\infty$ actually diverges logarithmically. To restore strict causality, the model either requires a high-energy decay term or an exact analytical formulation limited to a finite bandwidth, avoiding the mathematical inconsistency natively present in the 1986 derivation.

  • 2. Urbach Tail Extension

    The sub-bandgap region $E \leq E_g$ is modeled by an exponential Urbach tail appended to each oscillator's $k(E)$:

    $$ k_{mFB}(E) = \begin{cases} \displaystyle\sum_{i=1}^{q} \frac{A_i (E - E_g)^2}{E^2 - B_i E + C_i} & E > E_g \\[6pt] k_0 \exp\!\left(\dfrac{E - E_g}{E_u}\right) & E \leq E_g \end{cases} $$

    Mathematically, the derivative of $(E - E_g)^2$ at exactly $E = E_g$ is $0$. Therefore, to ensure a physically meaningful non-zero slope for the exponential tail (C¹ continuity), the Urbach transition is evaluated at a slight offset $E = E_g + \delta$ (similarly to the CERTUS implementation of the TLU model), ensuring a smooth gradient crossover controlled by $E_u$.

  • 3. Non-negativity Enforcement — Smooth Positivity Clamp

    With multiple oscillators, the total $k_{total}(E) = \sum_i k_i(E)$ can become negative in spectral gaps between resonances. The mFB model applies a differentiable positivity clamp using a softplus function (Likhachev 2015, Eq. 10):

    $$ k_{clamped}(E) = \frac{1}{\beta}\ln\!\left(1 + e^{\,\beta\, k_{total}(E)}\right) $$

    where $\beta \gg 1$ (typically $\beta = 100\text{ eV}^{-1}$) controls the sharpness of the clamp. In the limit $\beta \to \infty$ this reduces to $\max(0, k_{total}(E))$, but the smooth form preserves differentiability everywhere for gradient-based fitting. After clamping, the corresponding $n(E)$ is recomputed by KK to maintain causality.

  • 4. Tauc-like Onset — Modified mFB Formulation

    Likhachev (2016) proposed replacing the bare quadratic onset $(E - E_g)^2$ with a Tauc joint-density-of-states factor $(E - E_g)^2 / E$, exactly as in the Tauc-Lorentz model, but retaining the Lorentzian denominator of FB:

    $$ k_i^{mFB}(E) = \frac{A_i \,(E - E_g)^2 / E}{E^2 - B_i E + C_i} \quad \text{for } E > E_g $$

    The corresponding mathematically exact mapping transforms this via partial fraction decomposition into a zero-frequency pole and a standard Lorentzian:

    $$ \frac{(E-E_g)^2/E}{E^2-B_iE+C_i} = \frac{E_g^2/C_i}{E} + \frac{\left(1 - \frac{E_g^2}{C_i}\right)E + \left(\frac{B_i E_g^2}{C_i} - 2E_g\right)}{E^2 - B_iE + C_i} $$

    This rigorous separation yields a perfectly convergent KK integral that scales properly at high energies. The analytical integration generates exact arctangent and logarithmic sums that guarantee robust causality. This modified onset substantially improves the fit quality for disordered amorphous materials ($\text{a-C}$, $\text{a-Si:H}$) where the parabolic JDOS $\propto (E-E_g)^2/E$ is physically grounded, avoiding the asymptotic divergence of the canonical FB square-law.

Comparison with TLU and VB Models

When to prefer mFB over TLU:
  • Crystalline semiconductors: The multi-oscillator capability of mFB allows it to capture multiple distinct critical-point transitions (e.g., $E_1$, $E_2$, $E_1 + \Delta_1$ in GaAs, InP) unavailable to single-oscillator TLU.
  • Nitrides and wide-gap oxides (VIS/NIR): Materials such as $\text{TiO}_2$, $\text{Ta}_2\text{O}_5$, or $\text{SiN}_x$ with complex absorption edges benefit from the 2–3 oscillator mFB fit (Vogt et al., Thin Solid Films 519:3836, 2011).
  • Hybrid organic/inorganic films: Where separate electronic and vibrational oscillator bands are present in the same spectral window.
TLU remains preferred for: single-absorption-peak amorphous dielectrics (SiO₂, Al₂O₃, HfO₂) where the simpler parametrization and guaranteed KK compliance offer faster convergence with fewer degrees of freedom.

3.6 The Cody-Lorentz Model (CL)

The Cody-Lorentz (CL) model replaces the Tauc JDOS factor $(E-E_g)^2/E$ with a Cody gap function that saturates at high energies, and natively includes an Urbach tail with a smooth crossover:

$$ \epsilon_2^{CL}(E) = \begin{cases} \displaystyle \frac{(E - E_g)^2}{(E - E_g)^2 + E_p^2} \cdot \frac{A \, E_0 \, C \, E}{(E^2 - E_0^2)^2 + C^2 E^2} & E \geq E_t \\[8pt] \displaystyle \frac{E_t}{E} \, \epsilon_2^{CL}(E_t) \cdot \exp\!\left(\frac{E - E_t}{E_u}\right) & E < E_t \end{cases} $$

where $E_p$ is the Cody transition width, $E_t$ is the demarcation energy between band-to-band and Urbach regions, and $E_u$ is the Urbach energy. The CL model adds one parameter ($E_p$) versus TLU but converges naturally to $\epsilon_2 = 0$ at high energies (unlike the original FB model) and is Kramers-Kronig consistent. It is particularly suited for amorphous organic films and a-Si:H where the Cody gap function better describes the absorption onset.

3.7 The Brendel-Bormann Model (Gaussian Broadened Oscillators)

The Brendel-Bormann (BB) model generates non-Lorentzian (Gaussian-shaped) absorption lines by convolving a Gaussian distribution of resonance frequencies with a standard Lorentz oscillator:

$$ \tilde{\epsilon}_{BB}(E) = \sum_{j=1}^{q} \frac{1}{\sigma_j \sqrt{2\pi}} \int_{-\infty}^{+\infty} \frac{A_j \, E_{0j}^2}{E_{0j}^2 - (E + x)^2 - i\Gamma_j (E + x)} \; e^{-x^2/(2\sigma_j^2)} \, dx $$

where $\sigma_j$ controls the Gaussian inhomogeneous broadening width and $\Gamma_j$ is the Lorentzian homogeneous (lifetime) broadening. This convolution can be evaluated analytically via the Faddeeva function $w(z)$. The BB model is the standard choice for amorphous SiO₂ and Si₃N₄ in the mid-infrared (phonon absorption bands) where lineshapes are inherently non-Lorentzian due to structural disorder.

3.8 Data Pre-processing: Dynamic IR Noise Filtering

Spectral data often suffers from high-frequency noise in the deep infrared band (typically above 4000 nm) due to atmospheric absorption (e.g., CO₂, H₂O) and reduced detector sensitivity. To prevent this noise from interfering with the optimization algorithms without artificially flattening the relevant interference fringes, CERTUS-INDEX implements a Progressive Blended Savitzky-Golay filter upon data loading.

When noise is detected in the 4000–5200 nm band, the software applies two parallel Savitzky-Golay filters (polynomial order 2 to preserve extrema amplitudes) with specific, carefully chosen window lengths (which must be odd numbers to maintain symmetry):

  • 11 points (Light Filtering): Applied to the onset of noise around 4000 nm. With a typical spectrometer step of 1-2 nm, an 11-point window covers a narrow $\sim$10-20 nm range. This gently removes micro-noise while perfectly preserving the tighter interference fringes found in the near-infrared region.
  • 51 points (Heavy Filtering): Applied to the heavily degraded signal beyond 5200 nm. A 51-point window (covering $\sim$50-100 nm) aggressively crushes the high-frequency "snow". Because physical interference fringes naturally broaden significantly in the far-infrared, this wide window safely tracks the macro-curvature of the signal without clipping the genuine physical extrema.
Cross-fading (Linear Blending): To prevent abrupt mathematical discontinuities, the algorithm does not suddenly switch from the 11-point to the 51-point filtered signal. Instead, in the transition zone between 4000 nm and 5200 nm, it computes a dynamic linear blend (cross-fade) of both curves.
$$ S_{blend}(\lambda) = [1 - \alpha(\lambda)] \cdot S_{11}(\lambda) + \alpha(\lambda) \cdot S_{51}(\lambda) $$ $$ \text{where } \alpha(\lambda) = \max\left(0, \min\left(1, \frac{\lambda - 4000}{5200 - 4000}\right)\right) $$
At 4600 nm, for example, the resulting plotted point is exactly 50% of the 11-point curve plus 50% of the 51-point curve. This guarantees a mathematically smooth $C^0$ / $C^1$ continuity as the filtering strength scales proportionally with the increasing severity of the noise.

4.3 Objective Function (MSE)

The fitting minimizes a weighted Mean Squared Error combining R and/or T data:

$$ MSE = \frac{w_T \cdot MSE_T + w_R \cdot MSE_R}{w_T + w_R} $$

where:

$$ MSE_T = \frac{1}{N} \sum_{j=1}^{N} \left( T_{calc}(\lambda_j) - T_{meas}(\lambda_j) \right)^2 $$

Normalized mode divides calculated spectra by substrate reference values.

4.4 Analytic Gradient Acceleration (New in v26-01)

Traditional optical fitters rely on Finite Difference approximations to estimate parameter sensitivity. This approach is slow ($N_{params}+1$ evaluations per step) and prone to numerical noise (rounding or truncation errors), especially for complex and non-linear functions like Tauc-Lorentz.

CERTUS-INDEX implements a Fully Analytic Gradient ($\nabla \text{MSE}$), calculated via the strict formulation of the Chain Rule:

$$ \frac{\partial \text{MSE}}{\partial p_i} = \sum_{\lambda} \left[ \underbrace{\frac{\partial \text{MSE}}{\partial T} \cdot \frac{\partial T}{\partial n}}_{\text{TMM Sensitivity}} \cdot \underbrace{\frac{\partial n}{\partial \epsilon_1} \cdot \frac{\partial \epsilon_1}{\partial p_i} + \frac{\partial n}{\partial \epsilon_2} \cdot \frac{\partial \epsilon_2}{\partial p_i} }_{\text{Material Physics}} \right] $$

This novel implementation, powered by Numba-jitted kernels, allows the Quasi-Newton optimizer (L-BFGS-B) to "see" the exact vector slope of the error landscape at each iteration. This provides:

  • Absolute Precision: Elimination of artifacts tied to differential step size ($\Delta p$). The algorithm no longer gets "stuck" in numerical noise.
  • Massive Speed: The full gradient vector (all 7 derivatives) is calculated in a single algorithmic pass (vs 7+ for numeric).
  • Robustness: Guaranteed convergence toward the exact bottom of the well, even in very "flat" valleys of the parameter space.

5.1 Stage 1 — TLU Global Fit

Phase 1: PGLOBAL Global Search

The 7-dimensional parameter space contains many local minima due to interference fringes. CERTUS-INDEX uses the PGLOBAL algorithm — a hybrid stochastic/deterministic global optimizer:

  1. Uniform Sampling: Random points generated in the full 7D space. Parameters $A$ and $E_u$ are sampled on a logarithmic scale.
  2. Single-Linkage Clustering: The clustering algorithm groups evaluated points based on their relative Euclidean distance and objective function value. Points with similar costs that are geometrically close in the 7D hyper-space are merged into a common "basin" of attraction. This avoids launching multiple costly local optimizations toward the same minimum (redundancy). Reference: Global optimization by multilevel single-linkage clustering (A.H.G. Rinnooy Kan, C.G.E. Boender, 1987).
  3. Local Refinement: L-BFGS-B with analytic gradient is launched from each cluster center (budget: 1500 evals per cluster).
  4. Selection: The best solution across all clusters is retained.
Precision Modes:
  • Standard: 20,000 evaluations (fast, ~15-30s)
  • High Precision: 80,000 evaluations (thorough, ~60-120s)

Phase 2: L-BFGS-B Polish (Quasi-Newton)

The PGLOBAL result is refined using the L-BFGS-B (Limited-memory Broyden-Fletcher-Goldfarb-Shanno with Bounds) algorithm. It is a Quasi-Newton method that does not directly evaluate the second-derivative matrix (the Hessian, $H$), which would be numerically exorbitant for 7 dimensions.

Instead, L-BFGS-B maintains a history of position and gradient vectors (the "L" memory for "Limited", typically the last 10 to 20 iterations) to dynamically approximate the inverse Hessian matrix ($H^{-1}$). Coupled with the exact analytic gradient, the optimizer determines a near-perfect descent direction and rigorously handles boundaries (e.g., $E_g > 0.1$) via projection onto active constraints.

Phase 3: L-BFGS-B Local Polish

A fast L-BFGS-B local polish replaces the former multi-start coordinate descent:

  • Bounds: ±5% around the Phase 2 solution for all 7 TLU parameters.
  • Budget: 500 iterations, ftol=1e-14, gtol=1e-10.
  • Speed gain: ~2.6× faster than the previous 10-start coordinate descent.

Phase 4: Residual Uncertainty (3-way Grid Shift)

To quantify fitting stability, CERTUS-INDEX performs a 3-way split test:

  1. Data Decimation: Spectral data split into 3 interleaved subsets (indices $0,3,6\ldots$, $1,4,7\ldots$, $2,5,8\ldots$).
  2. Independent Fits: Each subset is optimized independently (L-BFGS-B + Nelder-Mead polish).
  3. Stability Envelope:
    $$ \Delta n_{res}(\lambda) = \max_{1 \le i < j \le 3} |n_i(\lambda) - n_j(\lambda)| $$ $$ \Delta k_{res}(\lambda) = \max_{1 \le i < j \le 3} |k_i(\lambda) - k_j(\lambda)| $$
    This defines the maximum absolute deviation across all 3 independent decimations, rigorously quantifying the structural instability of the fit.

Phase 5: Ultimate Refinement

The robust average of the 3 subset results seeds a final optimization on the full dataset:

  1. L-BFGS-B with extreme tolerances (ftol=1e-14, gtol=1e-14).
  2. Nelder-Mead derivative-free verification — catches gradient blind spots.
  3. The better of the two results becomes the final solution.

6. IR Pipeline (Spectrum > 2500 nm) — Workflow and Implementation

When the spectral range extends beyond 2500 nm, CERTUS-INDEX runs a two-stage pipeline. Stage 1 (TLU) is executed with lambda_max_fit = 2200 nm, so the TLU model is fitted only on 1000–2200 nm. The thickness and TLU solution from Stage 1 are then fixed; the second stage, implemented by IRGlobalModelWorker, refines $n(\lambda)$ and $k(\lambda)$ over the full wavelength range using a global parametric model, then a spline representation of $k$ in $\log k$, and finally an optional 90% T / 10% R refinement. The following describes the exact code flow so a reader can understand everything that was implemented.

6.1 Trigger and Data Preparation

  • Trigger: config.lambda_max > 2500.0. The UI logs: "Spectrum > 2500 nm detected: launching automatic two-stage TLU + Spline pipeline." (The word "Spline" in the message is legacy; the actual second stage is the IR Global Model + Phase 2.3 spline $k$ + Phase 2.1.)
  • Stage 1 TLU: Runs on data restricted to lambda_min–2200 nm. Phase 5 yields optimal thickness $d$ and TLU $n$, $k$ (extrapolated beyond 2200 nm for display).
  • Phase 2 input: Full-range wavelengths l_full (e.g. 1000–5200 nm), same target T/R (target_T, target_R from c.target_data["T"], ["R"]), substrate index, and optional absorbing-substrate data (k_sub_data, substrate_thickness_nm) for correct R/T when $\lambda \geq 2500$ nm. Thickness $d$ is fixed to the Stage 1 result.
  • Target data convention: Target values must be in the same convention as use_normalized: if use_normalized is True, targets are expected as $T/T_{sub}$ and $R/T_{sub}$ (relative); otherwise as absolute $T$, $R$. The cost and all live curves use this convention consistently (_compute_RT_from_config returns physical R, T, $T_{sub}$; then R_val = Rc/T_sub, T_val = Tc/T_sub when normalized).

6.2 Global Model: Sellmeier 2-Poles + Empirical k (8 Parameters)

The IR global model has 13 parameters: 5 for $n$ (Sellmeier 2-pole) and 8 for $k$ (empirical law). This model is used in Stages 0–2; Phase 2.3 replaces the k part by a spline in $\log k$.

Sellmeier 2-pole (5 parameters)

$n^2(\lambda) = A + \frac{B_1 \lambda^2}{\lambda^2 - L_1^2} + \frac{B_2 \lambda^2}{\lambda^2 - L_2^2}$ with $\lambda$ in µm. Poles $L_1$, $L_2$ are kept outside the fitted spectral range (e.g. 2.5–5.2 µm) to avoid singularities. Implemented in sellmeier_2poles_eval_nj.

Empirical k law — 8 parameters

$k(L) = 10^{-6} + \exp(s_1 L + p_1) + \exp(s_2 L + p_2) + A_k \exp\bigl(-|\frac{L - c}{w}|^\beta\bigr)$ with $L$ in µm. The two exponentials model rising/falling absorption edges; the last term is a super-Gaussian peak (center $c$, width $w$, exponent $\beta$). To avoid overflow and keep $k(L)$ smooth (no discontinuity at clip boundaries), the arguments of the exponentials are soft-saturated with $\tanh$ in $[-25, 5]$ instead of hard clipping. Implemented in k_law_8p_eval. Parameter beta is clipped to $[1, 8]$.

6.4 Objective and Guards (IRGlobalObjective)

  • Cost: Weighted MSE on full range: $\text{MSE} = (w_T \cdot \text{MSE}_T + w_R \cdot \text{MSE}_R)/(w_T + w_R)$. Normalized mode: $T_{val} = T_{calc}/T_{sub}$, $R_{val} = R_{calc}/T_{sub}$. Spectral weight $1/\lambda$ (normalized) to balance fit across wavelength.
  • Substrate: If k_sub_data and substrate_thickness_nm are set (e.g. Sapphire), R and T use calculationate_RT_single_layer_absorbing_substrate_array (Beer-Lambert in substrate).
  • Guards (return $10^{12}$ if violated):
    1) Sellmeier poles: $L_1$ or $L_2$ must not lie inside $[\lambda_{min}, \lambda_{max}]$ (µm).
    2) VIS continuity: On $\lambda \leq 2500$ nm, $|n_{Sellmeier} - n_{TLU ref}| \leq 0.20$.
    3) Physical: $n \in [1.2, 4.0]$, $k \leq k_{max}$ (0.02 if $\lambda_{max} \geq 2500$ nm, else 0.15), and np.isfinite(n).
    4) Optional: if n_ref_global is set (e.g. for 90% T sub-fit), $|n - n_{ref}| \leq 0.05$.

This yields a parsimonious spline (4–8 knots) with controlled RMSE loss.
    If Phase 2.3 does not improve over the Stage 2 (k_8p) result, the k_8p solution is kept and k_spline_knots_* remain None.

7. Stage 2 — Spline Refinement Pipeline

When the spectrum is ≤ 2500 nm, the optional second stage is this Spline Refinement. When the spectrum > 2500 nm, the automatic second stage is the IR Global Model (Section 6); the Spline pipeline below is a separate optional path, not used in the default >2500 nm flow.

After the TLU global fit converges, the optional Spline Refinement stage (SplineOptimizationWorker) replaces the TLU analytical model with a free-form cubic spline $n(\lambda)$, $k(\lambda)$, enabling accurate representation of materials whose dispersion deviates from the TLU shape (e.g., strong IR absorption bands, phonon resonances).

7.1 Knot Placement Strategy

Spline knots are placed at positions of maximum curvature of the TLU solution, computed independently for $n$ and $k$:

$$ \kappa_n(\lambda) = \left|\frac{d^2 n_{TLU}}{d\lambda^2}\right|, \quad \kappa_k(\lambda) = \left|\frac{d^2 k_{TLU}}{d\lambda^2}\right| $$

The wavelength range is divided into $N_{knots}$ equal bins; within each bin the position of maximum curvature is selected (stratified sampling). This concentrates knots where dispersion varies most rapidly while ensuring uniform spectral coverage.

Knot type Count Placement
VIS/NIR curvature (n) 15 Max $\kappa_n$ per bin
VIS/NIR curvature (k) 15 Max $\kappa_k$ per bin
IR extension 6 Fixed: 2500, 3000, 3500, 4000, 4500, 5000 nm
Boundary 2 $\lambda_{min}$, $\lambda_{max}$ (mandatory)

After merging and deduplication (minimum spacing 15 nm), gaps >400 nm are automatically filled with intermediate knots to prevent spline ringing.

7.2 Phase 2a — Pointwise IR Inversion (certus_pointwise_ir.py)

Before spline optimization, a wavelength-by-wavelength inversion is performed in the IR region ($\lambda \geq 2200$ nm) to produce a high-quality seed for the spline knots.

Wavelength Selection Mask

Wavelengths where $T_{rel} \approx 1$ (film nearly transparent) carry no information about the film and are excluded. The mask retains the 80% of wavelengths most distant from $T_{rel} = 100\%$:

$$ T_{rel}(\lambda) = \frac{T_{meas}(\lambda)}{T_{substrate}(\lambda)}, \quad \text{keep } \lambda \text{ where } |1 - T_{rel}| \geq P_{20}(|1 - T_{rel}|) $$

Per-wavelength Optimization

For each retained $\lambda_i$, a 2D L-BFGS-B minimization finds $(n_i, k_i)$ at the fixed TLU thickness $d_{TLU}$:

$$ \min_{n_i,\, k_i} \left[ \left(\frac{T_{calc}(\lambda_i)}{T_{sub}(\lambda_i)} - T_{meas}(\lambda_i)\right)^2 + \left(\frac{R_{calc}(\lambda_i)}{T_{sub}(\lambda_i)} - R_{meas}(\lambda_i)\right)^2 \right] $$

Outliers (deviation >3σ from the median using the MAD estimator) are replaced by the TLU seed. A 5-point sliding median filter smooths the VIS/IR boundary transition.

7.3 Phase 2b — Spline L-BFGS-B Optimization (with Tikhonov Regularization)

The spline knots (piecewise parametric models) are optimized by L-BFGS-B. Each knot is a free parameter, but the spline itself connects cubic polynomials, guaranteeing the continuity of the functions ($C^0$), their first derivatives ($C^1$), and their second derivatives ($C^2$).

To avoid "overfitting" optical noise, which would result in non-physical ripples in the index profile, a Tikhonov smoothing penalty (Regularization) is added to the global objective function.

Region $\Delta n$ bound $\Delta k$ bound
VIS ($\lambda \leq 2200$ nm) ±0.05 ±0.01
IR ($\lambda > 2200$ nm) ±0.03 ±0.01

The Loss function minimized with the smoothing constraint (penalizing curvature via 2nd-order finite differences) is:

$$ \mathcal{L}_{spline} = \text{MSE}_{optical} + \alpha_{smooth} \sum_{i=1}^{N_{knots}-2} \left[ (n_{i+2} - 2n_{i+1} + n_i)^2 + (k_{i+2} - 2k_{i+1} + k_i)^2 \right], \quad \alpha_{smooth} = 10^{-4} $$

A weight $\alpha_{smooth}$ of 1e-4 drastically suppresses pseudo-periodic harmonics without erasing genuine singularities like IR phononic resonances.

A final L-BFGS-B pass jointly optimizes all degrees of freedom simultaneously (500 iterations, ftol=1e-14):

8. Frosted Glass Mode

8.1 Physical Problem

For single-side polished wafers or intentionally roughened substrates, the back surface scatters light instead of reflecting it coherently. Standard TMM equations are invalid.

8.2 Mathematical Treatment

CERTUS-INDEX models this as an infinite substrate where back-reflections are eliminated:

$$ R_{frosted} = \left| \frac{n_{film} - n_0}{n_{film} + n_0} \right|^2 + \text{(thin-film interference terms)} $$

The code uses calculate_reflection_infinite_substrate_array which:

  • Computes front-surface reflection via TMM.
  • Adds incoherent substrate absorption (no interference).
  • Ignores back-surface Fresnel contribution.

8.3 Reference Calculation

The frosted substrate reference is computed via:

$$ R_{substrate}^{frosted} = \left| \frac{n_{sub} - 1}{n_{sub} + 1} \right|^2 $$

Unlike polished substrates where back-reflection creates interference fringes.

10. Key Features

10.1 Urbach Tail Analysis

Crucial for analyzing the quality of deposited films. A high $E_u$ indicates high disorder or impurities. CERTUS-INDEX quantifies this explicitly via the TLUParameters structure, allowing process engineers to optimize deposition energy.

10.2 Frosted Glass Mode

Specifically designed for measurements on roughened (frosted) back-side substrates. The code mathematically removes back-side reflections to isolate the thin-film signal, essential for single-side polished wafers.
